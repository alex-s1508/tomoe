# Ryoku: configuração manual

O perfil e as capturas desta pasta são referências para configurar o Ryoku
manualmente. O instalador não importa o perfil nem aplica as capturas.

- `ryoku-profile.ryoprofile`: perfil para importação manual.
- `screenshots/`: imagens de referência da configuração.

O ajuste opcional da barra SUMI fica em `sumi-fix/` e pode ser instalado ou
removido pelo menu do Tomoe (`./tomoe install` / `./tomoe uninstall`).
