# Arquivo histórico do Tomoe

Este diretório guarda apenas material antigo que não é usado pelo instalador.
Nada aqui é copiado para o sistema.

| Diretório | Conteúdo |
|---|---|
| `ascii/` | ASCII de 76 colunas que não é mais usado nos cabeçalhos. |
| `fastfetch/` | Configuração antiga do Fastfetch e o script de injeção do logo. |
| `kitty/` | Configuração antiga do Kitty. |
| `ryoku-hyprland/` | Perfil, capturas de tela e patches do período Ryoku + Hyprland. |

Os assets estéticos (ASCII, PSDs, imagens e wallpapers) continuam em
`dotfiles/assets/`.
